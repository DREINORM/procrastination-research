# Habit RPG — исследовательские данные

Набор показателей из научных публикаций и официальной статистики для предварительного обоснования проекта **Habit RPG** (приложение для формирования привычек с игровыми механиками, ориентированное на студентов).

Данные собраны из разных источников и не образуют единую выборку. Подробнее — в разделе [Ограничения](#ограничения).

## Содержимое репозитория

| Файл | Описание |
|---|---|
| `habit_rpg_research_data_ru.csv` | Таблица из 15 показателей (UTF-8 с BOM, открывается в Excel без перекодировки) |
| `README.md` | Описание данных, ограничения и источники |

## Описание столбцов

| Столбец | Описание |
|---|---|
| `id_показателя` | Технический идентификатор показателя (латиницей) |
| `значение` | Числовое значение показателя |
| `единица` | Единица измерения (см. ниже) |
| `размер_выборки` | Число участников исследования **или** число исследований в обзоре (зависит от строки, см. `примечания`); пусто, если выборки нет |
| `число_исследований_или_вузов` | Число исследований в метаанализе или вузов в опросе/мониторинге |
| `год_публикации` | Год публикации источника |
| `совокупность_или_охват` | К какой группе относится показатель |
| `показатель` | Что именно измерено |
| `ссылка_на_источник` | Ссылка на первоисточник |
| `примечания` | Доверительные интервалы, расшифровка доли, оговорки |

### Единицы измерения

| Значение | Что означает |
|---|---|
| `процент` | Доля от указанной группы (респондентов, населения) |
| `процент рассмотренных исследований` | Доля научных работ в обзоре, где применялась техника (не доля людей) |
| `g Хеджеса` | Стандартизированный размер эффекта в метаанализе (не процент) |
| `человек` | Абсолютная численность |
| `минут в день` | Среднее время использования |

## Ограничения

- Показатели получены из разных исследований, стран, выборок и лет. Их нельзя сводить в один процент или одну диаграмму.
- Графики стоит строить отдельно по каждой из пяти групп выше.
- Данные по США и по студентам-медикам нельзя переносить на российских студентов.
- `g Хеджеса` — размер эффекта, а не доля.
- Охват Telegram показывает использование платформы населением, а не спрос на Habit RPG.
- Столбец `размер_выборки` не всегда означает число людей: в строках про техники формирования привычек это число исследований.
- Для оценки реального спроса нужен собственный опрос студентов; его результаты предполагается хранить отдельным CSV-файлом.
