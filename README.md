# Habit RPG — исследовательские данные

Файл `habit_rpg_research_data.csv` содержит показатели из научных исследований и официальной статистики для предварительного обоснования проекта.

## Важно
- Это не единый набор наблюдений: показатели получены из разных исследований, выборок, стран и лет.
- Не объединяйте их в один общий процент и не стройте график, где несопоставимые показатели выглядят как одна серия.
- Для графиков выбирайте отдельные группы: прокрастинация; цифровые техники формирования привычек; охват Telegram; численность студентов.
- Данные США и медицинских специальностей нельзя выдавать за показатели российских студентов.
- Показатель Hedges' g — стандартизированный размер эффекта, а не процент.
- Охват Telegram показывает использование платформы населением, а не интерес к Habit RPG.
- Для актуальной оценки спроса рекомендуется провести собственный опрос студентов и добавить его результаты отдельным CSV-файлом.
- Перед финальной сдачей откройте первоисточники и проверьте методологию, даты и формулировки.
